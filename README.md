## 📌 프로젝트 소개

키오스크는 고령층만의 문제가 아닙니다. 매장마다 다른 UI, 복잡한 옵션 선택, 잘게 쪼개진 할인·간편결제 방식 때문에 **전 세대가 '디지털 피로도'를 겪고 있습니다.**

EASY CAFE는 UI를 예쁘게 바꾸는 데서 그치지 않고, **사용자의 행동을 감지해 문제를 자동으로 해결하는 로직**으로 키오스크의 진입 장벽을 낮추는 카페 주문 키오스크 웹 서비스입니다.

- 국내 무인기기 보급 대수 약 536K대, 3년 새 2.5배 증가 (한국지능정보사회진흥원,2024)
- 키오스크 이용자 2명 중 1명(51.3%)이 불편·피해 경험 (한국소비자원,2022)


## 🎯 해결하려는 문제

| Pain Point | 내용 |
|---|---|
| 도와줄 사람 없는 매장 | 바쁜 시간대에는 직원의 실시간 응대가 어려워 주문이 막혀도 방치됨 |
| 너무 복잡한 메뉴 | 카테고리와 옵션 선택이 복잡해 초기 단계부터 선택 피로가 큼 |
| 오류 시 탈출구 없음 | 주문이 진행되지 않거나 실수했을 때 스스로 해결할 방법이 없음 |
| 혼란스러운 결제 방식 | 할인·적립·간편결제 수단이 지나치게 세분화되어 선택이 어려움 |

## ✨ 핵심 기능

### 1. FAQ 시스템 (키오스크 + 관리자 페이지)
- 질문 클릭 시 프론트엔드가 백엔드 API로 비동기 신호를 보내 **조회수를 실시간으로 증가**
- 누적 조회수 기준 **실시간 인기 질문 TOP 3**, 카테고리별 1위 질문에 **'인기 1위' 배지**를 동적으로 표시
- 관리자 페이지(통합 관리 센터)에서 FAQ를 **등록·수정·삭제(CRUD)** 하고, 설명용 이미지를 첨부하면 재부팅 없이 키오스크 화면에 즉시 반영 (Supabase 연동)

### 2. 스마트 헬퍼 (30초 미반응 자동 도우미)
- 모든 클릭 이벤트를 구독하고, **30초 이상 아무 반응이 없으면** 화면 정체·주문 포기 상태로 판단
- 그 순간 FAQ 팝업을 큰 안내 문구와 함께 오버레이로 자동 호출
- 사용자가 FAQ를 읽는 동안에는 타이머를 중지

### 3. 바코드 원스텝 결제
- 사용자가 쿠폰인지 간편결제인지 고를 필요 없이, **어떤 바코드를 카메라에 대도 자동 분류**
- 바코드 앞자리(prefix)를 DB와 대조해 종류를 식별 (예: `880` 카카오톡 선물하기, `123` KT VIP 할인)
- 간편결제(네이버페이, 카카오페이 등), 선물하기 잔액 우선 결제, 통신사 10% 할인 후 남은 금액 결제를 지원
- 할인·쿠폰 적용 후 남은 금액은 추가 결제로 자동 유도

## 🔄 사용자 흐름

## 🚀 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/silvia32849/AI-.git
cd AI-
```

### 2. 백엔드 실행 (Flask) · 터미널 1

```bash
pip install flask supabase
python main.py
```

http://localhost:8000 에서 FAQ 페이지가 열립니다.

### 3. 프론트엔드 실행 (React) · 터미널 2

```bash
cd frontend
npm install
npm start
```

http://localhost:3000 에서 키오스크 화면을 확인할 수 있습니다.

> 백엔드를 먼저 실행한 뒤 프론트엔드를 실행해 주세요.


## 🔧 한계점 및 개선 방향

| 영역 | 한계 | 개선 방향 |
|---|---|---|
| FAQ | 한 사람의 연속 클릭으로 순위가 왜곡될 수 있음, 시즌성 무시 | 일정 시간 내 연속 클릭 제한, 시간 가중치 알고리즘, 자동 리셋 스케줄러 |
| 스마트 헬퍼 | 모든 화면에 동일한 30초, 기준이 시간에만 한정, 시각 안내만 제공 | 화면별 타이머 차등, 사용자 행동 패턴 분석, 음성 안내 추가 |
| 바코드 결제 | 실제 PG사 연동 없는 시뮬레이션, 카메라 각도·조명·저해상도에 따라 인식률 차이 | PG사 API 연동, AI 기반 바코드 보정, 예외 처리 강화 |

## 🌱 프로젝트 의의

- **기술적 성과**: React, Flask, 카메라 API를 연동해 추가 장비 없이 동작하는 가벼운 결제 환경 구현
- **사회적 의의**: 특정 취약 계층에 한정하지 않고, 전 연령층이 느끼는 인지적 장벽과 심리적 압박을 줄이는 데 초점
- **향후 방향**: 음성 안내, 머뭇거림 등 사용자 행동을 실시간으로 감지하는 능동형 도우미로 고도화
